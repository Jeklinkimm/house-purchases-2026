# 우리 집 구매 노트

[공개 페이지 열기](https://jeklinkimm.github.io/house-purchases-2026/)

로그인 없이 볼 수 있는 2026 이사 구매 목록입니다. GitHub Pages로 배포하며 방문자는 기록을 수정할 수 없습니다.

- 제품 이미지·구매 링크·참고 가격·수량·구매 상태
- 확인된 주문일·배송예정일·실제 도착일, 배송 캘린더
- 공개 가능한 항목의 변경 이력

`site/data/purchases.json`은 비공개 구매 노트에서 필요한 필드만 골라 만든 공개 스냅샷입니다. 주소·이메일·주문번호·운송장·비공개 메모·원본 주문내역은 포함하지 않습니다. 쇼핑몰 계정에 연결하지 않으며 자동 조회를 실행하지 않습니다. 수집한 사실만 업데이트하고 확인되지 않은 배송일을 추정하지 않습니다.

## 업데이트

1. 실제 주문내역을 확인하고 비공개 구매 노트에 근거와 함께 저장합니다.
2. 최신 `list_house_purchases` 결과를 저장소 밖 또는 ignored `.private/` 안에 임시 저장합니다.
3. `node tools/export-public.mjs <비공개 JSON 파일> site/data/purchases.json`을 실행합니다. 필드 허용 목록을 통해 비공개 값은 배제합니다.
4. 필요한 사진을 `site/assets/products/`에 추가합니다.
5. 변경 파일을 검수해 main에 push하면 Pages가 다시 배포됩니다.

초기 데이터의 가격·장바구니 상태는 대부분 2026-10-13 확인값이며 물막이·실리콘 선택은 2026-10-20 기록입니다. 주문내역 확인 시각은 페이지에 별도로 표시합니다. 미확인 값을 구매·배송 완료로 바꾸지 않습니다.

## 2026-10-20 주문내역 대조

오늘의집은 사용자가 평소 계정임을 확인한 로그인 계정의 최근3개월 주문이0건이며, 쿠팡은2026-09-17 이후 주문목록1~3페이지 및LED 검색을 대조했습니다. 현재28종과 일치하는 주문을 확인하지 못해 기존 상태를 유지했고 배송일을 추정하지 않았습니다. 공개 화면에 플랫폼별 확인 시각·범위·결과를 표시합니다.

GitHub Actions는 JavaScript·CSS를 내용 해시가 붙은 파일명으로 배포해 갱신 후 이전 브라우저 캐시와 섞이지 않도록 합니다.

## 위시리스트와 금액 합계

2026-10-20 사용자 요청으로 RA911 샤워바·모두라이프 거울장을 위시리스트로 이동하고 도무스905SS 문손잡이를2개로 변경했습니다. `status=wishlist`는 현재 구매하지 않는 보관 목록이며 취소 주문을 의미하지 않습니다. 위시리스트·구매취소·반품 품목은 합계에서 제외합니다.

상단 예상 상품 합계는 실제 상품 결제액이 등록되면 그 금액, 그 외에는 수량×참고 단가를 합산합니다. 수량·가격이 미정이면 합계에 넣지 않고 미산정 목록에 표시합니다. 배송비·설치비·쿠폰은 상품 합계에 포함하지 않습니다. 이번 변경 기준 상품 합계1,235,340원(15종), 미산정11종, 위시리스트2종입니다.
